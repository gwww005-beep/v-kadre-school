# В кадре

Презентационная версия сайта школы моделинга и актёрского мастерства. Утверждённый первый экран: «Школа моделинга и актёрского мастерства. Свобода проявляться. В кадре и в жизни».

Сайт работает без сборки: HTML, CSS и JavaScript. Можно открыть `index.html` или разместить содержимое этой папки на статическом хостинге. GitHub Pages публикует ветку `main`, корень `/`.

## Что показано

- Четыре модуля единой программы с упражнениями и результатом практики.
- Возрастные сценарии: от 13 лет, без направления 4–12.
- Преподаватели с иллюстративными портретами и раскрывающимися подробностями.
- Места под три видео, бесплатное первое занятие, маршрут обучения, FAQ.
- Три пакета с пустыми ценами. На телефоне программы и пакеты переключаются вкладками; преподаватели листаются горизонтально.
- Черновики политики обработки данных, согласия, cookie, условий и реквизитов.

## Перед реальным запуском

Это презентация, а не открытая запись. В `site-config.js` оставлены `demo: true`, `leadsEnabled: false`, `legalApproved: false`, `priceApproved: false`. Форма проверяет поля и показывает демонстрационное сообщение; данные никуда не отправляются и не сохраняются. На GitHub Pages PHP не выполняется.

Замените демонстрационные контакты и реквизиты; утвердите программы, условия, цены и юридические тексты. Цены задаются в `plans` для `start`, `practice`, `direction`: число `price` и понятный период оплаты `period`. Имена и опыт преподавателей не выдуманы — пока показаны роли. Изображения созданы ИИ, реальные фотографии учеников и педагогов необходимо добавить отдельно с разрешением на публикацию. Реальных видео пока нет.

Публичная версия не содержит секретов, базы заявок или подключённой аналитики. Не добавляйте личные данные, пароли и ключи в репозиторий.

## Проверка

Проверены мобильные вкладки, раскрытие модулей, меню и демонстрационная форма. Все используемые шрифты, скрипты и изображения локальные. Внешних библиотек и CDN нет.
